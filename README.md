📖 Hayatın Gerçek Öğütleri

Tarihe mal olmuş düşünürlerin ve yazarların hayat öğütlerini bir araya getiren, Bootstrap tabanlı responsive bir web sitesi.
✨ Özellikler
🏠 Ana Sayfa — Karşılama alanı (hero section) ve siteye kısa giriş
🏆 En Çok Okunan Öğütler — İbn Haldun, İlber Ortaylı, Fernand Braudel gibi isimlerden seçilmiş, kart yapısında öne çıkan öğütler
🧭 Navigasyon Menüsü — Anasayfa, Hakkımızda, Üye Ol, Yorum Yap, Giriş Yap sekmeleri
📱 Tam Responsive Tasarım — Masaüstü ve mobil ekranlarda (hamburger menü ile) sorunsuz görüntüleme
🎨 Özel Tipografi — Google Fonts üzerinden "Lobster Two" fontu ile özgün başlık stili
🛠️ Kullanılan Teknolojiler
HTML5
CSS3 (özel stil dosyası: öğüt.css)
Bootstrap (grid sistemi, navbar ve responsive bileşenler için)
Google Fonts
📁 Proje Yapısı
├── index.html          # Ana sayfa
├── css/
│   ├── bootstrap.min.css
│   ├── all.min.css     # İkon kütüphanesi
│   └── öğüt.css         # Özel stiller
└── demo.gif            # Tanıtım GIF'i
🚀 Kurulum ve Çalıştırma
Depoyu klonlayın:
bash
   git clone https://github.com/kullaniciadi/hayatin-gercek-ogutleri.git
Proje klasörüne girin:
bash
   cd hayatin-gercek-ogutleri
index.html dosyasını tarayıcıda açın veya VS Code'da Live Server eklentisiyle çalıştırın:
VS Code → Live Server yükleyin → index.html üzerinde sağ tık → "Open with Live Server"
